HELP & RESOURCES

Frequently Asked Questions & Guides

Everything you need to know about getting started, migrating your notes, and data security.

Where is my note data stored?

Notes uses an embedded SQLite database with WAL mode and dedicated file storage for attachments. In Docker deployments, your data lives in a persistent Docker volume on your server.

Can I migrate notes from other tools?

Yes! The Migration & Backup Wizard automatically detects legacy notes in browser localStorage and allows importing/exporting standard JSON backup files in one click. Google Keep exports and Markdown (.md) files can be imported from Account Settings → Import & Export Notes.

Does Notes support Markdown and shortcuts?

Yes, full Markdown is supported including tables, checklists, code blocks, headings, blockquotes, and keyboard shortcuts like ⌘S (save), ⌘K (search), and ⌘B / ⌘I formatting.

Is multi-tenant workspace isolation guaranteed?

Every workspace is strictly isolated at the database query level with session authentication and role-based access checks, ensuring zero cross-tenant leakage.
